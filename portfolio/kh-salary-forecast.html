Problem Statement

The salary forecast is a vital input to how Kimley-Horn forecasts its net revenue. Leadership projects total net revenue for the firm with one equation:

How the salary forecast drives revenue
Net Revenue = Total Salaries × Multiplier × UT

Every dollar of error in the salary forecast is multiplied straight into the net revenue forecast, so a more accurate salary forecast means a more accurate picture of the firm’s revenue.

The legacy salary forecast was missing by millions of dollars. I set out to build a more accurate, data-driven model of total firm-wide salaries.

Our Approach

1. Pulling the Data with SQL

I wrote SQL queries against Kimley-Horn’s general ledger to pull total salary dollars for every month back to 2019. That history became the target the model learns to predict.

2. Building the Model in Python

I brought the data into VS Code and used Python to build a multiple linear regression model of aggregate salaries for the firm. The model’s inputs are:

  1. Number of employees by GLC group: headcount at each level of the firm
  2. Average hourly rate by GLC group: what each level is paid on average
  3. Date flags: month-of-year and holiday effects
  4. Intern season flags: the spring, summer, and fall swings in intern hiring

Because the model is built from headcount and pay rates, it moves with the business: as the firm hires or raises rates in a GLC group, the forecast responds directly.

3. Testing It Against the Legacy Model

I trained the model on historical months, then tested it on months it had never seen and compared its error to the legacy forecast’s. The new model reduced error by 77%, or $9.8M. Once validated, the model is refit every month on all closed periods to forecast the rest of the year, with a 95% range around each month’s prediction.

The Model in Python

salary_projection_model.py
import pandas as pd
import statsmodels.api as sm

# Monthly salary dollars from the general ledger (pulled with SQL), joined to
# headcount and average hourly rate by GLC group plus date and intern flags
df = (salary_df
      .merge(glc_inputs_df, on=["FY_CD", "PD_NO"], how="left")
      .merge(date_flags_df, on=["FY_CD", "PD_NO"], how="left"))

GLC_GROUPS = ["GLC_1", "GLC_2", "GLC_3", "GLC_4", "GLC_5", "GLC_6"]
MONTHS = ["JAN", "FEB", "MAR", "APR", "MAY", "JUN",
          "JUL", "AUG", "SEP", "OCT", "NOV", "DEC"]

features = (
    [f"Empls_{g}" for g in GLC_GROUPS]               # number of employees
    + [f"Avg_Hourly_Rate_{g}" for g in GLC_GROUPS]   # average hourly rate
    + [f"{m}_FLAG" for m in MONTHS]                  # month / date flags
    + ["COVID_FLAG", "Intern_Spring", "Intern_Summer", "Intern_Fall"]
)
TARGET = "Final_Salary_Dollars"

# Train on history, then test on months the model has never seen
train = df[df["YEAR_PERIOD"].between(201901, 202512)]
test = df[df["YEAR_PERIOD"].between(202601, 202609)].copy()

model = sm.OLS(train[TARGET], train[features]).fit()

test["Prediction"] = model.predict(test[features])
test["Abs_Error_%"] = (test["Prediction"] - test[TARGET]).abs() / test[TARGET]
print(f"Average absolute error: {test['Abs_Error_%'].mean():.2%}")

# Refit on every closed month and forecast the rest of the year
closed = df[df["YEAR_PERIOD"] <= 202609]
future = df[df["YEAR_PERIOD"].between(202610, 202612)]
final_model = sm.OLS(closed[TARGET], closed[features]).fit()

pred = final_model.get_prediction(future[features])
forecast = pred.summary_frame(alpha=0.05)              # 95% range
forecast = forecast[["mean", "obs_ci_lower", "obs_ci_upper"]]

Business Impact

Because net revenue is calculated as total salaries × multiplier × UT, cutting the salary forecast’s error by 77% directly sharpens the firm’s revenue forecast. Leadership now plans with a forecast that has averaged an error of a fraction of a percent per month, along with a clear 95% range for every month still to come.
