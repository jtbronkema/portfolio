Forecasting Demand for the Quarterly VBC 30% Off Sale

Python (XGBoost, joblib) | Machine Learning, Demand Forecasting, Parallel Computing, Excel Automation

Project Completed by: Jackson Bronkema, in partnership with Fresh Thyme Market’s VBC category managers

Note: All data on this page has been anonymized to protect confidential company information. Figures, charts, and screenshots are illustrative.

Problem Statement

Four times a year, Fresh Thyme Market runs a 30% off sale on its vitamins and body care (VBC) products. Before each sale, category managers have to decide how much of each of more than 750 products to order and how many units to send to each of the chain’s 70 stores. Ordering too much of a product leads to shrink (product waste), so I built a machine learning forecast to help them make those decisions.

Our Approach

The project had two parts: a demand forecast for every product at every store, and an Excel report that put those forecasts in front of the category managers in a form they could use when ordering.

The Forecasting Model

I used XGBoost machine learning models to forecast how many units of each VBC product every store would sell during the upcoming 30% off sale.

One model per store, per SKU
750+ VBC products × 70 stores = 50,000+ XGBoost models

Each product at each store got its own model, so every forecast reflects how that exact item sells at that exact location.

Scaling to 50,000+ Models

Training more than 50,000 models one at a time would have taken far too long, so I used Python’s joblib package to optimize and parallelize the code. Each product-store pair ran as its own task, and joblib spread those tasks across the computer’s CPU cores so many models trained at the same time.

Category Manager Excel Report

Using Python, I generated an Excel file that gave category managers, for every product at every store:

  1. How many units sold in each of the last 5 years of sales
  2. How many units we forecast to sell in the upcoming sale
  3. A 95% confidence interval around each forecast
  4. A graph of each forecast alongside its sales history

Category managers found the report extremely helpful when ordering product and deciding how many units of each product to send to each store.
